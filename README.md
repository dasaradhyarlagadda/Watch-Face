# Wear OS Companion App

A Wear OS and Android companion application that demonstrates real-time communication between a smartwatch and smartphone using Google's Wearable Data Layer API.

## Features
- Wear OS companion app
- Android companion app
- Watch-to-phone messaging
- Phone notifications triggered from the watch
- Real-time communication using MessageClient
- Built with Kotlin and Material 3

## Tech Stack
- Kotlin
- Wear OS
- Android SDK
- Google Play Services Wearable API
- Material 3

## Project Structure
- mobile/ - Android phone application
- wear/ - Wear OS application

## Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Connect an Android device and a Wear OS device/emulator.
4. Build and run both applications.
